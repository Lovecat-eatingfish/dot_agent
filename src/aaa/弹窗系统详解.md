# 弹窗系统详解 — getCurrentUserNeedShowPopupListV2 方法解读

> 方法位置: `AppPopupServiceImpl.java` 第 866 行
> 接口: `POST /app/popup`
> 用途: APP 端请求时，服务端实时计算并返回需要展示的弹窗

---

## 一、方法概述

这个方法是弹窗系统的核心，负责根据用户信息、AB 实验、人群包、频控规则等条件，决定给用户展示哪个弹窗。

**返回结果**: 每次只返回 **1 个弹窗**（轮询机制）

## 五、关键过滤条件汇总

| 过滤条件 | 说明 |
|---------|------|
| AB 实验关闭 | `enablePopupPush=false` → 不展示任何弹窗 |
| 设备系统 | `deviceSys` 必须匹配 (-1 表示通用) |
| 人群包 | `crowdLimit=0` 时，用户必须匹配人群包 |
| 观看时长 | `watchingDurationType` 1=≥, 2=≤, 3=区间 |
| 每日次数 | `popupCount` 限制，0=不限 |
| 推剧间隔 | 首页推剧弹窗有间隔时间控制 (默认30分钟) |
| canShowPush | `false` 时过滤掉 popupType=8 的通知弹框 |

## 六、轮询机制说明

**目的**: 避免每次展示同一个弹窗，实现轮换展示

**逻辑**:
1. 按优先级排序 (数字越小优先级越高)
2. 查上次展示的弹窗优先级
3. 找到优先级比上次高的下一个弹窗
4. 如果没有更高的，回到第一个 (循环)
5. 测试弹窗始终优先于正式弹窗
