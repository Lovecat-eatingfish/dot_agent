# 多语言系统详解

> 用途：了解项目的 i18n 实现方式

---

## 一、核心架构

这个项目的多语言是**完全自定义的**，没有用 Spring 的 `MessageSource`，翻译文本存在数据库 + Redis 缓存。

```
客户端请求 (Header: lang: "en_US")
    │
    ▼
JwtAuthenticationFilter
    ├── 读取 lang 请求头
    ├── 查 sys_lang 表 (langCode="en_US" → langId=2)
    └── 存入 UserContextHolder (ThreadLocal)
    │
    ▼
业务代码使用:
    ├── UserContextHolder.get().getLangId()  → 获取当前语言ID
    └── i18nUtil.getMessage(type, key, langId, defaultMsg)  → 翻译文本
    │
    ▼
翻译查找路径:
    Redis 缓存 → 数据库 (i18n_message 表) → 默认文案
```

---

## 二、核心表结构

### sys_lang（语言定义表）

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 语言ID | 1=中文, 2=英语, 4=韩语, 5=日语 |
| lang_name | 英文名称 | Chinese, English, Korean |
| chinese_lang_name | 中文名称 | 中文, 英语, 韩语 |
| lang_code | 语言代码 | zh_CN, en_US, ko_KR |
| lang_status | 是否启用 | true/false |

### i18n_message（翻译文本表）

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 主键 | - |
| message_key | 消息键 | "10000", "sign", "drama" |
| message_type | 消息类型 | 0=字典, 1=消息, 2=错误, 3=弹窗 |
| lang_id | 语言ID | 2 (英语) |
| message_value | 翻译内容 | "Check-in", "New Drama Push" |

---

## 三、消息类型 (messageType)

| 值 | 常量 | Redis 前缀 | 用途 |
|---|------|-----------|------|
| 0 | I18n_DICT | `DICT:i18n:` | 字典项翻译 |
| 1 | I18n_MESSAGE | `MSG:i18n:` | 通用文本翻译 |
| 2 | I18n_ERROR | `ERROR:i18n:` | 错误信息翻译 |
| 3 | I18n_POPUPS | `POPUPS:i18n:` | 弹窗文本翻译 |

## 四、使用方式

### 方式1: 静态方法（错误信息翻译）

```java
// 自动从 UserContextHolder 获取 langId
String msg = I18nUtil.getMessage("10000", "默认错误信息");
```

### 方式2: 实例方法（指定类型和语言）

```java
@Autowired
private I18nUtil i18nUtil;

// 指定 messageType 和 langId
String msg = i18nUtil.getMessage(BaseConstants.I18n_MESSAGE, "sign", langId, "签到");
```

### 方式3: 批量翻译

```java
List<I18nMessageDTO> list = new ArrayList<>();
I18nMessageDTO dto = new I18nMessageDTO();
dto.setMessageType(BaseConstants.I18n_MESSAGE);
dto.setKey("sign");
dto.setLangId(langId);
dto.setDefaultMsg("签到");
list.add(dto);

Map<String, I18nMessageDTO> result = i18nMessageService.batchGetMessage(list);
```

### 方式4: 自动翻译（通过 Result.failure）

```java
// Result.failure 内部会自动调用 I18nUtil.getMessage()
return Result.failure(10000, "默认错误信息");
```

## 五、翻译查找流程

```java
// I18nMessageServiceImpl.getMessage() 的逻辑:
1. 构建 Redis 缓存 key: {prefix}{langId}:{key}
   例如: "MSG:i18n:2:sign"

2. 查 Redis 缓存
   ├── 命中 → 返回
   └── 未命中 → 查数据库

3. 查 i18n_message 表 (messageKey + messageType + langId)
   ├── 命中 → 写入 Redis → 返回
   └── 未命中 → 降级查 I18n_MESSAGE 类型

4. 降级查询
   ├── 命中 → 写入 Redis → 返回
   └── 未命中 → 返回 defaultMsg
```

## 六、lang 请求头处理

在 `JwtAuthenticationFilter` 中：

```java
// 1. 读取请求头
String lang = request.getHeader("lang");

// 2. 查询语言表
SysLangDAO langDAO = langRepository.getOne(
    Wrappers.<SysLangDAO>lambdaQuery().eq(SysLangDAO::getLangCode, lang)
);

// 3. 找不到则默认英语
if (langDAO == null) {
    langDAO = langRepository.getOne(
        Wrappers.<SysLangDAO>lambdaQuery().eq(SysLangDAO::getLangCode, "en_US")
    );
}

// 4. 存入上下文
loginUser.setLanguage(lang);
loginUser.setLangId(langDAO.getId());
UserContextHolder.get().setLangId(langDAO.getId());
```

## 八、Redis 缓存结构

| 前缀 | Key 格式 | Value |
|------|---------|-------|
| DICT:i18n: | `{langId}:{dictId}` | 翻译后的字典名 |
| MSG:i18n: | `{langId}:{messageKey}` | 翻译后的通用文本 |
| ERROR:i18n: | `{langId}:{errorCode}` | 翻译后的错误信息 |
| POPUPS:i18n: | `{langId}:{popupKey}` | 翻译后的弹窗文本 |
